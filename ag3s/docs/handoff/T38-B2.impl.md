## 무엇을 했나 (평이한 요약 먼저)

로봇 self-filter 는 "점이 로봇 구(587 개) 안에 있나" 를 묻는다. 지금까지는 카메라마다 **두 번** 물었다 —
scene reconstruction 에서 voxel 로 줄인 점 13 만 개에, constraint generation 에서 같은 depth 를 다시 역투영한
50 만 개에 (잡고 있을 때는 쥔 구로 한 번 더). 매번 KD-tree 를 새로 짓고 Python 으로 구 587 개를 돌았다.

이제 카메라마다 **한 번**: depth 를 full-res 로 한 번 역투영하고, (점 × 구) 판정을 GPU 에서 float64 로 한 번
계산해 픽셀 마스크를 만든다. TSDF 는 그 마스크를 그대로 받고, voxel cloud 의 대표점은 **자기 픽셀의 판정** 을
읽는다 (대표점이 바로 그 역투영 점이므로 예전에 대표점을 직접 시험하던 것과 같은 판정이다). 쥔 구는 필터 모델에
이미 붙어 있으므로 held 픽셀 수도 같은 pass 의 열에서 나온다. GPU 판정은 scipy 와 **같은 산술을 같은 순서로**
해서 CPU KD-tree 와 비트 단위로 같다 — 재생 237 호출 · 경계 위 점 단위 테스트 모두 차이 0.

덤으로 `AG3S.reset` 뒤 GPU 상시 할당이 994 MiB 로 남던 것 (버려진 cuRobo mapper 가 cuRobo/warp 내부 참조 순환에
걸려 gen-2 GC 를 기다림) 을 reset 에서 한 번 `gc.collect()` 해 497 MiB 로 되돌렸다.

결과: replay 청크당 AG3S+TO 중앙 **1,726 → 1,086 ms** (−640 ms), 모든 출력 동일, 기준선 둘 소수점·프레임별 sha1 까지 동일.

## 마스크 판정 규칙 (두 backend 공통, `sphere_mask_parts` docstring 이 정본)

`d = p_i − c_j` (float64), `sq_ij = (dx·dx + dy·dy) + dz·dz`, `R_j = r_j + δ_j` (δ = per-link inflation, 쥔 구는 0):

| 양 | 규칙 | 근거 |
|---|---|---|
| hit | `sq_ij ≤ R_j·R_j` | scipy `query_ball_point` 의 내부 산술 그대로 (경계 ±1 ulp 600 시험에서 KD-tree 와 불일치 0; `sqrt(sq) ≤ R` 로 쓰면 41 개 불일치) |
| guarded | `sqrt((gx² + gy²) + gz²) ≤ ρ` — 활성 guard 이고 1 점 이상일 때만 | `np.linalg.norm(axis=1)` 의 합산 순서 (200 만 점에서 100 % 일치, 반대 결합은 88 %) |
| inside | guard 밖: `∃j hit_ij`. guard 안: `∃j hit_ij ∧ sqrt(sq_ij) ≤ r_j` | T19 의미 그대로 |
| protected | `guarded ∧ (∃j hit) ∧ ¬inside` | T19 `n_guard_protected` |
| held | `∃j∈held sq_ij ≤ r_j·r_j` (bare, guard 없음) | T32 H1 `robot_sphere_mask(points, hc, hr, 0.0)` 와 같음 |

**voxel cloud 의 keep/drop.** 판정은 점과 구만의 순수 함수다. voxel 대표점은 같은 역투영의 점 그 자체 (`voxel_downsample` 은
첫 점을 `(u, v)` 와 함께 고르고, cap 도 대표점 중에서 고른다; `PointCloud.select` 는 값을 복사할 뿐) 이므로
`drop(대표점) = mask[v, u]` 는 예전 규칙 "대표점을 직접 시험" 과 **정의상 같다**. 역투영의 `(u, v)` → 점 은 1:1 이다.
(CPU KD-tree 끼리도 "점 집합이 다르면 트리 모양이 달라 경계 ulp 에서 갈릴 수 있다" 는 이론적 여지가 있었는데,
GPU 판정은 점 집합과 무관한 순수 함수라 그 여지조차 없다.)

- chunk 크기 (1 행 · 777 행 · 1 행 미만) 가 답을 안 바꿈. guard 소속이 `np.linalg.norm` 과 비트 동일 (guard 구면 위 점 ±1 ulp).
- device 선택 (`cpu` · `auto` · 잘못된 이름 → `AG3SConfigError` · CUDA 없을 때 `cuda` → `RuntimeError`), 빈 입력 모양.
- `backproject` + `downsample_and_cap` = `reconstruct`.
- `depth_robot_mask` 한 번 = pre-B2 두 호출 (depth mask 픽셀 · guard 보호 수 · voxel cloud 점/uv/stats) — `cpu` · `auto` 둘 다.
- fused ESDF 경로: 프레임당 `robot_sphere_mask` 가 **카메라마다 full-res 로 정확히 한 번**, TSDF 가 받은 마스크 = `_robot_mask_for` 재계산, `n_depth_masks` · guard px 집계 동일, 캐시 소비됨.
- `process_observation(with_depth_mask=True)` 의 cloud · attention · stats = 예전 경로. primitive backend 는 voxel cloud 만 (예전 그대로).
- held: 쥔 구가 모델 꼬리 열로 한 pass 에 들어가고 `_mask_held_px` = 별도 `robot_sphere_mask(points, hc, hr, 0)`.
- reset: 순환에 걸린 builder 를 reset 이 수거 (`gc.disable()` 상태에서도), builder 없으면 `gc.collect` 안 부름.
