# T42 — 과일별 "장애물 없이 완벽 성공" episode 라이브러리 + 다양한 검정 장애물

> writer: lead (A0) · 2026-10-05 · 사용자 지시: "(1) 장애물 없는 상황에서 완벽하게 성공하는 episode 를 과일별로, 최소 총 5 개. (2) 그 episode 에서 장애물을
> 소환해 테스트 — 다양할수록 좋고, place 과정 장애물 · pick 과정 장애물 각각. 장애물은 검정색 추천." 순서: 1 → 2 (T41 과 병행).

## 1 — episode 라이브러리 (verifier)

- 후보: test split 1800–1999 에서 과일 (apple · orange · banana · pear) × 팔 (left · right) 별로 고른다. 사과 + 왼팔은 T39 기록 재사용 (두 seed 모두 E0 · E3b 성공한 episode).
- **"완벽 성공"** = 장애물 없이 **E3b 가 seed 3 개 모두 성공** (grasp · place, 기존 규칙). E0 도 같은 seed 로 돌려 기록 (비교 기준).
- 단계: 과일마다 후보 6 개 × seed 1 (E3b) → 성공한 것만 seed 2 개 더 → 3/3 인 것 선택. 목표: **과일마다 ≥ 1, 총 ≥ 5** (가능하면 과일마다 2, 팔 섞어서).
- 분석 스크립트 일반화: target 과일 · 팔을 episode 메타데이터에서 읽는다 (지금은 사과 qpos 38 · 왼손 27 하드코딩). E3b client `--safe-manipulators <arm>`.
- 코드: 현재 main (SUBTASK-g 포함) 의 **불변 snapshot**, `--no-subtask-gate` (사용자: gate off), autotune 0, `--policy-seed`, `--warmup-steps 1000`, 녹화.
- 산출: `T42-1.verify.json`, `figures/t42/t42-1-*` (과일별 성공 표 · 장면), `outputs/verify/T42/1/`.

## 2 — 다양한 검정 장애물 (implementer → verifier, 1 뒤)

- implementer (pi05_TO_hybrid, **H 가 끝난 뒤** — 같은 파일): 장애물 시각 geom 을 **검정** (config 로 색 지정 가능, 기본 검정). 새 slot (box 금지 — MuJoCo 거리 버그):
  **pick 단계** 장애물 (과일 옆 · 접근 경로 위의 검정 기둥 · 낮은 펜스 · 과일 위를 지나는 막대 등) · **place 단계** 장애물 (지금의 허들, crate 옆 기둥 등). 추가 · 제거는 지금처럼 config.
- verifier: 1 의 episode 마다 pick 장애물 · place 장애물 배치 (T40 F 방식: 기록 경로 재생으로 "그대로 가면 부딪힘", 리셋 겹침 없음, 비켜 갈 여유), E0 · E3b 실행 · 녹화.

## 사용자 추가 지시 (2026-10-05)

1. "pick 과정은 장애물과 크게 상관없다. pick 순간 사과가 그리퍼에서 빠져나와 실패하는 경우가 있다 → **pick 이 확실히 성공하는 episode** 에서 **허들을 피해 place** 하는 것을 보여주는 것이 중요."
   → T42-1 선택 기준에 **파지 견고성** 추가: seed 3 개 모두 grasp 성공 + 들어 올린 뒤 place 까지 사과가 손에서 빠지지 않음 (미끄러짐 0). T42-2 는 **place 단계 장애물 우선** (hurdle · crate_post),
   배치 조건에 "기록된 접근 · 파지 경로와의 최소 거리 ≥ 30 mm" (pick 에 영향 없음) 추가. pick 단계 장애물은 그 뒤 (선택).
2. "충돌 회피할 때 그리퍼의 방향을 벡터로 — 피하는 방향을 실시간으로 화살표로." → client 녹화 (3rd person mp4 · viewer) 에 **회피 화살표**: 매 step 의 TCP(refined) − TCP(policy reference)
   (= TO 가 정책 동작을 밀어낸 방향 · 크기), 문턱 이상일 때만, verdict/HOLD 별 색. 시각 전용 (물리 · 기록 불변). implementer (pi05_TO_hybrid) → T42-2 실행 snapshot 에 포함.
3. "1800 번 이상 episode 사용을 강제하지 않는다. 어느 episode 든 성공률이 높으면 된다." → 후보 풀을 train/val (0–1799) 까지 넓힌다 (정책이 학습한 분포라 성공률이 높을 수 있음 — 기록에 split 을 명시).
