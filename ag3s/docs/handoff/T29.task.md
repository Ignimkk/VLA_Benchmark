## 왜 지금 이것인가 — 측정 (T28 Phase 1)

**손가락 관절은 늘 0 = 닫힘**이다. 제약 모델과 self-filter 모델이 둘 다 그렇다.

## 구현에 요청하는 것 (→ implementer)

### 1. 손가락 관절 상태를 두 모델에 넣는다

- **촬영 시점의 개도**: 관측의 16D `state` 의 gripper 열(7: 왼손, 15: 오른손 — 측정 개도, 정규화)을 finger joint 값으로 되돌린다. 변환은 클라이언트가
  `rby1_state()`/`apply_action` 에서 쓰는 것의 **역함수**여야 한다 (값을 박지 말고 같은 정의에서 가져온다; P1-3c: 데이터셋 open 명령 = −0.045).
  **self-filter 모델**은 이 값으로 FK 한다 (그 이미지는 그 개도에서 찍혔다).
- **TO 계획 창 (K 스텝)**: 스텝 0 은 측정값, 스텝 k ≥ 1 은 청크의 gripper 열(명령) 을 finger joint 로. 실제 손가락은 명령을 ~2 스텝 늦게 따른다 (T22:
  1.013 → 0.904 → 0.712) — 어떤 모델을 택했는지와 이유를 impl.md 에. 손가락 관절은 **결정 변수가 아니다** (parameter) — `linearize` 의 Jacobian 은 팔 관절만.
- wire 를 바꾸지 않고 되면 바꾸지 않는다. 바꿔야 하면 impl.md 에 이유와 로컬 PC 동기화 대상.
- T22 의 reach (`ee_finger_l1` 원점 ↔ 조작 대상) 는 이제 실제 손가락 위치에서 잰다 — 값이 바뀐다. 기본 `reach` 는 건드리지 말고 verifier 가 다시 잰다.

### 2. self-filter 구 모델이 로봇을 덮게 한다 (inflation 이 아니라 구로 — cuRobo 원칙)

- 위 누수 body (`link_left_arm_2`·`link_left_arm_3`·`wrist_bracket_l/r`·`d435i_body_l/r`, 그리고 측정에 나오는 나머지) 를 MJCF mesh 에서 맞춘 capsule/구로 덮는다
  (`gap_filling_capsules`·`UNCOVERED_LINKS` 와 같은 방식). 왜 `link_left_arm_2` 가 그렇게 새는지 (URDF capsule 이 mesh 보다 가늘거나 어긋남) 먼저 확인해 impl.md 에.
- 제약 모델에는 넣지 않는다 (제약 범위는 gripper — T27). 자기 필터만.
