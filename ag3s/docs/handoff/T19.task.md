# T19 — self-filter 가 조작 대상을 지우지 않는다

> writer: lead (A0) · 2026-09-28 · 읽는 쪽: implementer, verifier
> 근거: [지침](AG3S_GRASP_FAILURE_IMPLEMENTATION_GUIDE.md) §3 · §10-2, [T14.audit](T14.audit.md) §2·§4.1, [계획](AG3S_GRASP_FIX_PLAN.md)

## 왜 지금 이것인가

`robot_sphere_mask()` 는 로봇 sphere 의 `r + inflation(0.05 m)` 안의 점을 **물체 정체와 무관하게** 지운다. 같은 판정이
depth 의 robot mask (`_robot_mask_for`) 에도 걸린다. 손이 사과 50 mm 안에 들어가면 사과 관측이 통째로 사라진다 — T14 를
MuJoCo 에 되살려 잰 값: t=96 에 사과 픽셀이 head 378 · wrist 2,497 개 보이는데 **통과 0**. 그 뒤 grounding 이 crate 로 넘어간다.

이것이 사슬의 **입구**다. 다만 지침 §3.1 이 못박은 대로 **보존만 고치면 사과가 더 확실한 장애물이 된다** — 접촉 허용(T20)이
같이 와야 한다. 이 STEP 은 보존 쪽만 하되, 그 사실을 impl.md 첫 줄에 적는다.

```
카메라 depth → [로봇 마스크] → attention lifting → target grounding → TSDF/ESDF
                 ^^^^^^^^^^ 여기
```

## 구현에 요청하는 것 (→ implementer)

### 1. link 그룹별 inflation (`config.py` · `stages/robot_filter.py` · `runtime/pipeline.py`)

- `PointCloudConfig` 에 **link 별 inflation 재정의** 를 둔다 (예: `self_filter_inflation_by_link: dict[str, float]`,
  키는 link 이름 **또는** `serve_safe.LINK_GROUPS` 의 집합 이름 `arms` · `gripper` — 그쪽 규약과 같게).
  **기본값은 비어 있고, 비어 있으면 지금 동작과 글자 그대로 같다.** 숫자를 코드에 박지 않는다.
- `robot_sphere_mask` 가 sphere 별 inflation 배열을 받게 한다 (`inflation: float | ndarray`). 호출부 둘(cloud 필터 ·
  depth mask) 이 **같은** 배열을 쓴다 — 두 곳이 갈리면 grounding 과 TSDF 가 다른 로봇을 본다.
- sphere → link 이름은 `robot_model.sphere_link_names` 에서 온다. 모르는 link 이름은 **오류** (조용히 전역값으로 물러나지 않는다 —
  `capsule_radius_scale_by_link` 와 같은 규율).

### 2. 확정 target 근방 보호 (같은 파일들)

- 파이프라인이 **직전 프레임에 확정한 target centroid** (`self._target_confirm.held_centroid`) 와 반경 `R` 안의 점은 inflation
  을 쓰지 않고 **sphere 실제 반지름 (`inflation = 0`)** 으로만 판정한다 — 로봇 표면은 여전히 지워지고, 그 옆의 사과 표면은 남는다.
  `R` 은 config (`self_filter_target_guard_radius`), **기본 0 = 꺼짐**.
- 보호가 **켜졌는지, 어느 centroid·반경으로, 몇 점이 보호됐는지** 를 stats 와 시작 로그에 남긴다.
- 지침 §3.3 의 경고: "사과 주변을 무조건 예외로 만들면 로봇 표면이 함께 남을 수 있다" — 그래서 예외가 아니라 **inflation 0** 이다.
  단위 테스트로 박아라: 보호 구 안의 로봇 sphere 내부 점은 여전히 지워진다.

### 3. 실제 적용 설정을 기록 (`serve_safe.py`)

- `serve_safe.build_ag3s` 가 `AG3SConfig.from_dict` 에 `pointcloud` 를 넘길 때 inflation 관련 값을 **CLI 로 줄 수 있게**
  (`--self-filter-inflation-link LINK_OR_GROUP=M` · `--self-filter-target-guard R`). 안 주면 기본값.
- 시작 로그에 **실제 유효 inflation 표** (link 별) 와 self-filter 모델 sphere 수를 찍는다. 지침 §3.2: YAML 의 0.02 가 이 경로에
  닿지 않는다는 사실을 로그가 말해야 한다.

### 4. 손대지 않을 것

- `TargetConfirm` · grounding 의 선택 규칙 (T20). `_target_ball` · `_build_esdf` · `curobo_*` (T21).
- `trajopt/**` (T18·T24 가 열려 있다) — `serve_safe.py` 의 **AG3S 생성·시작 로그 부분만** 예외.
- 커밋하지 마라. 포트 8123 서버는 건드리지 마라.

## 이 STEP 이 답하는 질문

**손이 사과에 닿는 동안에도 사과 관측이 살아 있는가 — 그리고 로봇은 여전히 지워지는가?**

## 되돌아올 지점

- link 별 inflation + guard 로도 `base` 누수가 돌아오면 → 렌더 기반 exact mask (지침 §3.3).
- guard 반경이 이웃 물체(orange, 105 mm)까지 덮어야 하는 씬이면 → T20 의 ID 기하로 guard 를 잡는다.
