## F3-2. 규칙과 문턱 — 무엇을 근거로

| 규칙 | 값 | 근거 |
|---|---|---|
| (i) centroid 이동 ≤ 기준 기하의 bounding radius | 숫자 없음 (그 물체의 반지름) | task: 테이블 위 물체는 손이 닿기 전 움직이지 않는다. 기준 = 현재 기하(파지 전에는 anchor 이거나 anchor 를 90 % 이상 덮은 refine). anchor 기준에서 정상 사과 155 연결의 shift/r 최대는 **0.62** 다 (직전 기하 기준이면 1.09) |
| (ii) narrowest·middle 비 ∈ [1/k, k] | **k = 2.5** (`clustering.manipulated_extent_ratio`) | anchor 기준에서 정상 사과 155 연결의 최대 fold 는 narrowest **2.07**, middle **2.08** 이다(ep1807 t=88, 손에 잘린 조각). k 를 여기에 딱 맞추면 정상 조각이 `association_rejected` 가 된다. 그러면 그 조각이 **challenger 로 세어져 3 청크 뒤 switch** 되고, 새 id 의 기하가 조각이 된다. 실제로 (a) 만 켜고 k=2.5 로 돌린 E3b ep1800 r2 는 원래 id 유지가 23 → 7 청크로 줄었다. 그래서 여유 ~20 % 를 둔다. 1.8·2.0·2.2·2.5 는 E3 전체 결과가 ±5 청크 안에서 같았다 |
| (b) refine ⇔ coverage(anchor, 관측, 5 mm) ≥ c | **c = 0.9** (`clustering.manipulated_anchor_coverage`) | 병합 anchor 에서 사과 점 비율은 0.53 (ep1808) / 0.57 (ep1800) 이다. 손이 사과를 가린 뒤 관측의 coverage 는 **0.33–0.49** 였다(ep1808 r1 t=104–136, ep1800 E3b r2 t=136–160). 사과 일부만 가려진 관측은 0.5–0.8 이다. c=0.9 면 anchor 를 최대 10 % 까지만 버릴 수 있다. 기준이 **채택 anchor** 라 버리는 양이 청크마다 누적되지 않는다. 직전 기하 기준으로 합성 시험을 하면 5 단계 침식으로 orange 로 넘어갔다(`test_e3_merged_blob_…`). 정상 사과의 full view 도 시점이 바뀌면 coverage 가 0.19–0.9 로 흔들린다. 그런 관측은 refine 되지 않고 anchor 가 남는데, 파지 전에는 물체가 움직이지 않으므로 해가 없다 |
| coverage 거리 | 5 mm = `TargetConfirm.overlap_distance` (AG3S 안에서 cloud voxel) | "같은 표면을 관측 해상도에서" — T26 destination overlap 과 같은 정의 |
| 적용 조건 | `frozen=False` · admissibility checked · 두 키가 None 이 아님 · 기준 기하 있음 | 파지 중(closing…held)에는 물체가 손과 같이 움직인다 → T26 그대로 따라간다. 해제 뒤에는 그때 기하가 새 anchor (`source: observed`) |

`tolerance`(60 mm)는 건드리지 않았다. `switch`(admissible, score ≥ 0.1, 3 프레임)도 그대로다. 거절된 cluster 는 보통 challenger 로 센다(`test_a_rejected_cluster_is_still_an_ordinary_challenger`).

### 알려진 한계

1. **사과 단독 한쪽 관측은 "전체" 가 원리적으로 안 된다.** 관측점은 앞면뿐이라 centroid 가 GT 중심보다 16–20 mm 카메라 쪽에 있고, 반지름은 42–46 mm 다.
   그래서 뒷면(중심 + 34 mm → centroid 에서 50–54 mm)이 ball 밖이다. ep1807·T14·T17 이 이 경우이고, F3 로는 바뀌지 않는다. ball 규칙(`_target_ball`, pipeline — 내 파일 아님)의 문제다.
2. **동결 구간은 범위 밖이다.** 파지 시도(`grasp_active`) 중에는 task 정의대로 F3 가 꺼지고 기하가 관측을 따라간다.
   E3a ep1800 r2 t=160–320 에서 손이 닫힌 채 사과를 들지 못했고, 그동안 기하가 banana 조각으로 옮겨 갔다. 해제 뒤에는 그것이 새 anchor 가 된다.
   "닫혔지만 들리지 않은" 구간도 anchor 를 지킬지는 판정이 필요하다(T30a F4 attach 정의와 맞물림).
3. **T26 switch 는 그대로다.** 이웃이 score ≥ 0.1 로 3 청크를 이끌면 새 id 가 된다(E3b ep1808 r1 t=256 pear).
