## 왜 지금 이것인가

T16(`--no-collision`, w_smooth 0, w_continuity 0)은 refined ≡ reference 0.00° 였는데도 HOLD 25/34 로 실패했다 — **판정과 HOLD 가 여전히 돌았기 때문**이다.
사용자가 요구하는 실험 1 은 "TO 만" 이다: AG3S·ESDF·판정·HOLD 가 **없어야** 한다. 지금 코드에는 그 조합이 없다 (`--no-safe` 는 TO 도 끈다,
`--no-collision` 은 판정을 남긴다, `--safe-shadow` 는 refined 가 아니라 reference 를 실행한다).

## 구현에 요청하는 것 (→ implementer)

### 1. client `--safe-gate off` (`client.py` · `pi05_TO_hybrid/rby1_bringup/pi05_infer.py`)

- 서버 판정·`verdict_reasons` 와 무관하게 **refined 청크(`actions`)를 실행**한다. HOLD 를 만들지 않는다.
- 예외는 청크가 **도착하지 않은** 경우(timeout·오류·dimension) 하나다 — 실행할 청크가 없다. 그때는 T23 의 fixed HOLD 를 쓰되 `comms` 로 세고 크게 찍는다
  (실험에서 이것이 0 이어야 한다).
- 시작 로그에 크게: "GATE OFF — 판정은 기록만, 실행에 쓰지 않는다". planning frame 에 `gate: {mode: off, would_hold: <reasons 기준이면 HOLD 였나>, kinds}` 를 싣는다
  (판정이 켜졌다면 무엇이 막았을지를 같은 실행에서 볼 수 있게).
- `--safe-shadow` 와 다르다: shadow 는 **reference** 를 실행한다, gate off 는 **refined** 를 실행한다. 둘을 같이 주면 거절.

### 2. server `--no-perception` (`serve_safe.py` + 새 모듈 가능, 예: `trajopt/to_only_policy.py`)

- π0.5 → **TO** (충돌 행 0, AG3S·depth·ESDF·attention 모델·grasp latch 없음) → 같은 wire 응답 (`actions` = refined, `actions_reference`, `to` metrics,
  `safe=True`, `verdict_reasons=[{kind: "no_perception"}]`). 클라이언트(`--safe-remote`)가 그대로 받을 수 있어야 한다.
- attention 모델 두 번째 사본을 **올리지 않는다** (필요 없다). `--record-constraints` 를 주면 청크마다 reference · refined · 관절별 편차 · limit overshoot · SQP metrics 를 남긴다.
- `safe_policy.py` 는 **건드리지 않는다** (T26 소유). 새 wrapper 로 만들어라.

### 3. server `--no-limits` (`problem.py` · `limits.py` · `config.py` 중 필요한 곳)

- TO 에서 joint position box · velocity · acceleration 행을 뺀다 (진단). trust region·initial anchor 는 SQP 장치이므로 남긴다 — 무엇을 남겼는지 impl.md 에.
- 추적 항만 있고 limit 이 없으면 refined ≡ reference 여야 한다 — unit test 로 확인.
- `--w-track 0` 거절은 그대로 (T15).

### 4. `--links` 기본값 `arms` → `gripper` (`serve_safe.py`, 사용자 판정)

- 거리장 충돌 제약은 손바닥 둘 + 손가락 넷(`GRIPPER_LINKS`)에만. `arms`·`all` 은 옵션으로 남는다. 시작 경고의 방향을 뒤집는다 (이제 `arms`/`all` 이 비기본).
- self-filter 모델(전신 218 구)은 그대로다 — 제약 범위와 무관.
