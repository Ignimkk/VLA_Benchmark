## 아홉 사건의 **정확한 발생 프레임**을 낸다

```
target acquired → target latched → grasp contact → attached
→ destination attention → transport → placement → detached → task state reset
```

각 사건에 대해 **프레임 번호와 그것을 무엇으로 판정했는지**를 함께 적는다. 판정 근거는
가능하면 **MuJoCo 참값**(접촉·물체 위치·그리퍼 관절)과 **AG3S 내부 상태**(latch phase·
`ag.attached`·grounding)를 **나란히** 둔다 — 둘이 어긋나는 프레임이 이 게이트의 알맹이다.

## 합격 조건

| 무엇 | 합격 |
|---|---|
| **조작 대상 ID** | attention 이 목적지로 옮겨가도 바뀌지 않는다. 잠금(latch)이 정체성을 붙든다 |
| **attach 후** | 쥔 물체가 로봇 충돌 기하에 **포함**되고 장애물 필드에서 **빠진다** |
| **detach 후** | 이전 상태가 제거된다. 다음 과제에 target·목적지가 남지 않는다 |
| **잔상** | 누적 TSDF 의 잔상을 프레임별로 기록. 감쇠는 기본 끔이므로 **끈 상태의 잔상 지속 프레임 수**를 낸다 |

## 앞서 ep1800 에서 나온 것 — 이 기록에서 다시 확인한다

600 스텝 ep1800 기록에서 잡힌 셋이다. **그 기록은 운반이 없어 결론이 반쪽이었다.** ep1807 에서
같은 것을 보고, 사라지는지 남는지 가른다.

1. **잠금이 `PLACED` 에서 빠져나오지 못한다** — `GraspLatch.update()` 에 그 분기가 없어
   2 차 파지에서 `attach()` 가 울리지 않고 1 차 대상에 묶인 채였다. ep1807 은 놓기가 실제로
   일어나므로 **`PLACED` 이후가 처음으로 의미를 갖는다.**
2. **잠긴 대상과 실제 접촉 대상이 달랐다** — 캐시된 `latched_target` 의 최근접 참값 과일이
   banana(9 mm)인데 실제 MuJoCo 접촉은 apple 이었다 (둘은 93 mm 떨어져 있다).
3. **`runner_up_score` 키가 없다** — `safe_policy._run_latch` 가 `metrics.get("runner_up_score", 0.0)`
   로 읽는데 그 키가 `target.metrics` 에 없어 전 프레임 0.0 이다. 잠금이 *"1 등과 2 등의 격차"*
   로 확신을 판단하려던 장치가 무력화돼 있다. **2 가 3 의 결과일 수 있다** — 확인해라.
