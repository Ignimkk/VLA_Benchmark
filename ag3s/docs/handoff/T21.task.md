# T21 — fine / target-free 창이 손의 실행 경로를 덮는다

> 근거: [지침](AG3S_GRASP_FAILURE_IMPLEMENTATION_GUIDE.md) §5 · §10-3, [T24.verify](T24.verify.json) (접근 구간 손끝 변위의 원인), [T20.impl](T20.impl.md), [T19.verify](T19.verify.json), [계획](AG3S_GRASP_FIX_PLAN.md)
> **착수 조건: T22 impl 이 닫힌 뒤** (`runtime/pipeline.py` 충돌).

## 왜 지금 이것인가

T24 가 접근 구간(T17 t=72–120)의 손끝 변위 **중앙값 51 mm · 최대 195 mm** 의 원인을 특정했다: QP 가 받은 행은 전부 `ee_finger_l1/l2`
의 **coarse 20 mm 계층** 행이고, target-free 는 켜져 있었는데도 reference 의 최소 clearance 가 −34.7 mm 였다. target-free 층이 **fine
한 겹뿐**이라 손가락이 그 창 밖이면 사과가 든 coarse 층이 답한다 (`curobo_field.target_free_distance`: 창 밖 → `d`). T14 seq 12–21 에서는
손가락 질의점이 fine 창 안에 든 chunk 가 **0/8** 이었다 (T14.audit §2).

T20 이 창 중심을 manipulated centroid 에 붙들어 두므로 "창이 crate 로 달아나는" 경우는 닫혔다. 남은 것은 지침 §5.1 의 분리다 —
**정밀 거리장의 배치는 현재 손 자세와 곧 실행할 손의 경로가 정하고, 제외할 물체는 manipulated ID 가 정한다.** 둘을 attention centroid
하나에 묶지 않는다.

```
카메라 depth → 로봇 마스크 → grounding → [TSDF/ESDF: coarse 전체 + fine 창 + target-free 창] → 거리장 어댑터 → SQP
                                                          ^^^^^^^^^^^^^^^^^^ 창을 어디에 놓나
```

## 구현에 요청하는 것 (→ implementer)

### 1. 창 배치 (`fields/curobo_builder.py` · `runtime/pipeline.py:_build_esdf`)

- fine 창(과 target-free 창)의 중심·범위를 **권한 있는 link 의 sphere 가 지금 있는 곳과 실행 창(K=8 step) 동안 지나갈 곳**으로 정한다:
  `q_now` 와 정책 reference 청크의 앞 K step 에 FK 를 걸어 권한 link sphere 중심의 AABB 를 구하고, sphere 반지름 + 마진 + 보간·기울기
  계산에 필요한 여유(복셀 2 칸)를 더한다. **창 크기(128³ × 5 mm = 0.64 m)를 넘으면** 우선순위는 현재 손 자세 → 실행 구간 순이고,
  넘친 사실을 기록한다.
- manipulated 물체가 창 안에 있어야 target-free 제외가 뜻이 있다 — 손과 물체가 멀 때는 (접근 초기) 지금처럼 물체 중심이어도 된다.
  **규칙을 하나로**: 창 = 손 swept AABB ∪ manipulated AABB 가 들어가면 그것, 안 들어가면 손 우선 + 기록.
- 제외 기하(`_target_ball`)는 **manipulated 기하만** 쓴다 (T20 이 이미 넘긴다). 창 확대와 제외 영역 확대를 혼동하지 않는다 (지침 §5.3-3).
  **guard 반경 규칙도 여기서** (사용자 판정 2026-09-28): T19 의 `self_filter_target_guard_radius` 가 0 이 아니면 그 값을, 0 이면 **manipulated
  반지름 + pad(복셀 1 칸)** 를 쓴다 — 물체별로 정해지고 숫자를 박지 않는다.

### 2. 후보의 창 이탈 검사 (`trajopt/linearize.py` 또는 `sqp._finish` 근처 — 어느 쪽인지 impl.md 에 이유)

- TO 가 낸 refined 청크의 권한 link 질의점이 **어느 계층에서 답을 받았는지** (`fine` / `coarse` / `outside`) 를 행마다 기록한다
  (`worst_row` 신원에 `tier` 추가). 접근 구간의 손가락 행이 coarse 에서 답을 받으면 그 사실이 `notes` 에 난다.
- 지침 §5.3-4: 후보가 창을 벗어나면 **재계산/재배치하거나 검증 불가를 명시**한다. 이 STEP 에서는 **명시**까지만 — 재계산 루프는 T25 뒤에.
  창 밖을 자유 공간으로 읽거나 coarse fallback 을 접촉 허용 성공으로 기록하지 않는다.

### 3. 기록

`esdf_stats["window"]`: 중심·범위·근거(`hand_swept` / `manipulated` / `overflow`)·권한 link 질의점 중 창 안 비율·계층별 행 수.

  `sqp.py` 의 후보 선택 규칙 (T24). cuRobo 를 만지면 skill `curobo-esdf` 먼저.
