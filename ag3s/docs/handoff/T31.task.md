## T31a — G1 + G2 (→ implementer; `trajopt/limits.py` · `trajopt/config.py` · `trajopt/sqp.py` · `trajopt/serve_safe.py` · `trajopt/bringup.py`)

- **G1**: TO 의 관절 위치 limit 은 **제어 대상 로봇의 실제 범위**에서 온다. sim 서버는 이미 `--model-xml` 을 로드한다 — 그 MJCF 의 `jnt_range` (그리고 actuator `ctrlrange` 와 일치하는지 확인)를 쓴다. 실기용으로 config 에서 명시할 수 있게 한다 (`limits.source: model_xml | urdf | config`).
  URDF 는 형상(구 모델)에만 쓴다. 시작 로그에 관절별 URDF vs 사용값 표를 찍고, 다르면 크게. `position_margin 0.02` 는 유지. 속도·가속도 limit 의 출처도 확인해 impl.md 에 (MJCF 에 없으면 지금 값 유지 + 출처 명시).
- **G2**: (i) TO 시간 예산을 "linearize + 최소 2–3 SQP 반복" 이 들어가게 — E3 실측 linearize 67 ms, QP ~2 ms, check ~4 ms. sim 은 동기식이므로 예산을 벽시계가 아닌 **반복 수 우선**으로 둘 수 있게 (config). 기본값은 근거와 함께.
  (ii) 초기 iterate 가 **limit 만** 어기고(충돌 위반 0) 받아들여진 후보가 없으면, 거절된 QP 후보 대신 **reference 의 최소 투영** (`clamp_to_limits`, 그 결과의 충돌 검사 통과 시)을 반환한다. T24 규칙(초기 iterate 가 적격이면 그것)은 유지.
- 테스트: E3b chunk 310 (t=88, 1808 r1) 재현 — MJCF limit 이면 overshoot 0 → refined ≡ reference. limit 만 어기는 합성 사례 → 반환이 최소 투영.
