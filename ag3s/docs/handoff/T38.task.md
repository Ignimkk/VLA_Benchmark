## Phase A 결과 요약 (T38.profile.verify.json, 2026-10-01) → Phase B 범위 (lead 제안, 사용자 판정 대기)

- **GPU 시간은 청크의 ≈ 1 %** (커널 5.7–7.4 ms + memcpy 2.7–4.4 ms). 3 초는 거의 전부 CPU Python/numpy 다. replay AG3S+TO 2,547 ms + recorder 245 ms.
- grounding 1,018 ms 의 대부분은 계산이 아니라 **`cKDTree(..., workers=-1)` 가 256 코어 기계에서 청크당 스레드 ≈ 2,138 개를 띄우고 거두는 비용** — 같은 입력·같은 결과로 `workers=1` 이면 grow_region 612–1,107 → 9 ms · dbscan 질의 127–170 → 3 ms · NN 125–162 → 0.6 ms.
- `robot_sphere_mask` (구 587 개 Python 반복 + KD-tree) 가 청크당 6–9 회 = 672 ms; depth 역투영 2 회 중복; KD build 24 회/청크.
- ESDF: `_labels_from_sites` 134 ms · tier D2H 50 MB/청크 · TO linearize 97 ms 의 대부분이 128³ tier 마다 `np.gradient` 전체 재계산.
