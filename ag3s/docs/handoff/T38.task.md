## Phase B — 병렬화 (→ implementer, worktree 에서)

Phase A 결과로 lead 가 범위를 정한다. 원칙: 점군 단위 연산(필터 · 거리 · clustering · 복셀화)을 torch/warp 로 GPU 배치, 카메라·cluster 단위 반복을 벡터화, 쓰이지 않는 산출물은 만들지 않는다, cuRobo 와 같은 GPU 텐서를 공유해 host↔device 복사를 줄인다. 결과 동치성은 기존 테스트 + 기록 재생 + 두 기준선으로 확인.
