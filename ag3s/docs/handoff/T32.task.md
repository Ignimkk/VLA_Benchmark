## H1 + H2 (→ implementer)

- **H2 쥔 물체 기하**: 파지 확인(T30a F4 의 attach) 순간 관측된 물체 점(anchor/분할된 사과 기하)에 **구를 맞춘다** (한 개 bounding 이 기본, 필요하면 소수 개 — 근거와 함께). 부모 frame 은 **손바닥 (`ee_left`/`ee_right`)** — 손가락 link 는 닫힘에 따라 움직인다 (T29). 반지름 0 점 표현은 제약에서 은퇴.
  기록: 구 중심·반지름 · 부모 link · attach 시점 GT 가 있으면 비교용 (verifier 가).
- **H1 쥔 물체 = 로봇의 일부 (cuRobo attach 방식)**: attach 된 동안 그 구를 **self-filter 구 집합에 더한다** → 쥔 물체의 픽셀이 로봇처럼 지워져 TSDF 에 들어가지 않는다 (inflation 0 규칙 그대로 — 구가 물체를 덮어야 한다: 관측 점 최대 거리 + 작은 pad, 근거와 함께). detach 에서 뺀다.
  제약 쪽: 쥔 물체 구는 **환경(crate·table·기타)과의 충돌 질의점**으로 남는다 (지금 destination 여유 규칙 그대로). 손가락 ↔ 쥔 물체는 질의하지 않는다 (같은 강체).
  seed 제거(`n_attached_seeds_excluded`) 는 H1 뒤 필요 없으면 은퇴, 남기면 이유를.
- **H3 잔상**: H1 로 새 적분이 멈춘다. **이미 적분된** 쥔 물체 흔적(파지 전 테이블 위 사과 자리 · 파지 직후 몇 프레임)이 남는지 H1 뒤 측정으로 보고, 남으면 쥔 물체 구의 swept 영역을 TSDF 에서 비우는(free 로 갱신) 방식으로. 측정 없이 넣지 않는다.
- 파일: `ag3s/runtime/pipeline.py` (attach/detach · self-filter 구 조립) · `ag3s/robot_models/**` · `ag3s/stages/robot_filter.py` (필요 시) · `ag3s/fields/**` (H3 필요 시) · `trajopt/grasp_latch.py`·`safe_policy.py` (attach 호출부만). 테스트 `tests/ag3s`·`tests/trajopt`.
