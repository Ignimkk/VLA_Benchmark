# T43R2 — 구현: 쥔 과일 질의 구 = 몸통 덮개 (바닥 반구 포함) · J1 lift 는 받침 가까이에서만

> writer: ag3s-implementer (A1) · 2026-10-05 · 읽는 쪽: verifier, scribe, lead
> benchmark HEAD `d1ae608` 위 · **커밋하지 않았다** · 기본 off (`--held-body-cover`)

## 무엇을 했나 (평이한 요약 먼저)

쥔 과일의 TO 질의 구를 **과일 몸통 전체**를 덮도록 다시 만든다 (`--held-body-cover`, 기본 off).
attach 순간 과일은 받침 위에 놓여 있었으므로 바닥이 받침면이다 — 맞춘 구 (주 구) 아래에 **같은 반지름의
바닥 구**를 받침까지 (+ 운반 중 미끄럼 5 mm) 내려 놓는다. J1 lift (T34) 는 **몸통이 받침 + 띠 + 10 mm
안에 있을 때만** (지금 자세 또는 이번 청크의 reference 실행 창) 붙이고, 운반 중에는 붙이지 않는다.
거리장 · self-filter · TSDF free 부피는 **off 와 같은 구** (J1 lift 된 맞춘 구) 를 그대로 쓴다 — 바뀌는 것은
TO 가 묻는 질의 구뿐이다. 왼손 · 오른손 같은 코드 경로다 (parent = `palm_link_for`).

기록 재생 (T43 S 의 사과-막대 접촉 8 run): 몸통 구가 사과 mesh 를 **최대 1.1 mm 바깥** 까지 덮고
(off: 6.8–16.3 mm), 접촉 청크의 TO 쥔 물체 행이 8/8 run 에서 **≤ 0** (off: +4.9 … +12.9 mm) 이다.

## 설계

### 1. 몸통 덮개 — `held_object.body_cover_spheres` (base 좌표, attach 의 스냅샷 자세)

| 경우 | 구 | 근거 |
|---|---|---|
| **구형 몸통** (`mode="sphere"`: 맞춤 받아들임 · 수평으로 길쭉하지 않음) | 주 구 `(c, R + pad)` + **바닥 구** `(c − Δ·n, R + pad)`, `Δ = max(0, h − R) + slip` (`h` = 받침 위 맞춘 중심 높이) + 두 구 밖 관측 점 덩어리마다 덮개 구 (H2 규칙) | 촬영 순간 바닥 = 받침면. 같은 반지름 두 구의 허리 `√(R² − Δ²/4)` |
| 맞춘 구가 받침에 **한 pad (5 mm) 이내로** 못 미침 | `R ← min(h, max_radius)` 로 올리고 바닥 구는 `slip` 만 | 가린 cap 의 반지름 과소 (T41 ep1807: 29.0 mm, `h − R` = 3.1 mm). 그보다 멀면 구가 아닌 몸통 (배: 위 cap 에 맞춘 중심이 받침 위 43 mm, R 27 mm) — 옆으로 키우면 이웃 과일을 읽는다 (재생 1차에서 측정) |
| **구간 덮개** (`mode="segments"`: 맞춤 물러남 · 수평 주축 > 1.6 × 폭 (폭 ≥ 맞춘 지름) · 덮개가 슬롯을 넘음) | 관측 점 + 받침면 발자국 + `slip` 내린 사본을 수평 주축을 따라 `k = ⌈길이/폭⌉` (2–4) 구간 → 구간마다 상자 중심 + 최대거리 + pad | H2 merge 의 큰 구 하나 (바나나, J1 lift 가 그 바닥 overhang 을 가리고 있었다 — lift 를 걷으면 crate 에서 −40 … −57 mm) 를 피한다 |

상수 (`held_object.py`): `HELD_BODY_SLIP_M = 0.005` — T40/T41 접촉 5 run (고유) 에서 attach → 접촉까지 사과
중심이 손바닥 frame 에서 중력 쪽으로 2.1–4.5 mm 움직였다 (재생 측정, 아래 §표 2). `HELD_ELONGATION_RATIO = 1.6`
(사과 · 오렌지 · 배 mesh 수평 66.6×66.6 · 61.5×61.5 · 60.3×58.7 mm). pad = 한 fine voxel (5 mm, H2 와 같다).
슬롯 = `constraint.max_attached_primitives` (4) — 구 개수는 그것을 넘지 않는다.

### 2. J1 조건부 — `AG3S._frame_held_attached` (매 프레임, `_constraints` 에서)

- **받침 가까이** ⇔ 몸통 구 바닥의 최솟값 ≤ `band + held_lift_hysteresis_m` (10 mm), 평가 자세 = `robot_state`
  **와** `execution_path` (정책 reference 의 실행 창 K 행, T21 이 fine window 에 이미 넘기는 것) 중 어느 하나.
  평면 = 이 프레임의 지지면 + attach 평면 (테이블은 안 움직인다; 지지면이 빈 프레임에도 선다), 그중 몸통
  아래 가장 높은 수평면 (`support_plane_under`, J1 과 같은 규칙). `band` = J1 이 attach 에서 잰 띠.
- 가까우면 J1 lift 된 몸통 구 (attach 때 `lift_off_support` 를 몸통 구에 — 스냅샷 자세는 평면, attach 자세는
  평면 + 띠) 를 쓰고, **이 프레임 자세들에서도** 평면 + 띠 위로 더 올린다 (같은 손바닥 고정 방향; J1 은
  attach 자세만 쟀다 — T42 ep983 배: 10 청크 뒤 3.7 mm 더 눌렸다). 멀면 lift 없는 몸통 구.
- 이유: 띠 (거리장이 받침을 d = 0 으로 보는 두께, 8.5–9.0 mm) 안의 바닥 구가 테이블 행에서 음수를 읽는 것은
  과일이 **받침 위에 놓여 있어서** 이지 충돌이 아니다. 그 위에서는 받침에서 떨어져 있으므로 lift 하지 않는다 —
  막대처럼 받침 위 장애물이 바닥 반구로 들어오는 것을 가리지 않게. 10 mm = 두 fine voxel: 띠에서 멈춘
  내려놓기가 다음 청크에 lift 로 넘어가고, 면 · 맞춤의 voxel 단위 잡음으로 뒤집히지 않을 만큼.
- 경로를 보는 이유: crate 바닥은 테이블 면 + 8 mm 이고 따로 지지면으로 잡히지 않는다 (기록의 support mask: 바닥
  z≈0 · 테이블 0.80–0.84 m 뿐). 바닥까지 내리는 청크는 q_now 에서 50–100 mm 위에서 시작한다.

### 3. 바뀌지 않는 것 (flag on 이어도)

`self._attached` (J1 lift 된 맞춘 구 = off 와 같은 객체) 가 계속 **TSDF free 부피** (`_held_free_points`) · seed
제외 · self-filter 복사본 (`_held_filter_local` + slip 20 mm) · `held_observation` 의 기준이다. 그래서 **거리장은
off 와 한 복셀도 다르지 않다** — 기록 거리장 위의 재생이 live 와 같은 필드를 본다. 몸통 구로 TSDF 를 비우면
막대 · crate 벽처럼 과일에 닿은 장애물의 표면을 지울 수 있어 일부러 넣지 않았다.

flag on 일 때 프레임의 geometry 는 `dataclasses.replace(_attached, primitives=…)` 이고, `AG3S.attached` 가 그
객체를 돌려준다 (safe_policy 의 `constraints_match_state` 의 `is` 비교가 그대로 참).

  (base, 스냅샷) · `body_parent_frame` · `lifted_parent_frame` · `lift` · `band_mm` · `frame`
  (`near_support` · `near_row` (0 = q_now, i ≥ 1 = reference 실행 창 i−1 행) · `min_bottom_gap_mm` ·

  closed loop 에서는 계획이 달라지므로 그 뒤 프레임은 다르다.
- **알려진 것 (보고)**:
