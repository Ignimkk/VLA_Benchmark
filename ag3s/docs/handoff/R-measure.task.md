# R-measure — 16D 단독으로 다시 잰다 (14D 와 비교하지 않는다)

> writer: lead (A0) · 2026-09-25 · **사용자 판정으로 R 의 성격이 바뀌었다**

## 무엇이 바뀌었나

R 은 *"14D 에서 나온 수치 7 개가 16D 에서도 그대로인가"* 를 묻는 STEP 이었다.
**사용자 판정(2026-09-25): 14D 와 비교하지 않는다. 14D 기록은 기준에서 파기하고 16D 로
새로 측정한다. AG3S 자체도 16D 에 맞춰 수행한다.**

그래서 R 의 물음이 바뀐다:

| | 옛 물음 | **새 물음** |
|---|---|---|
| R | 14D 값이 16D 에서도 같은가 | **16D 에서 이 값은 얼마인가** |
| 값 표 | `14D 값 │ 16D 값 │ 달라졌나·왜` | **`16D 값 │ 어떻게 쟀나 │ 표본`** |
| 판정 | "바뀌었다 / 안 바뀌었다" | **"16D 의 기준선은 이것이다"** |

**14D 값을 옆 칸에 놓지 않는다.** 비교가 없으므로 *"달라졌나"* 열도 없다.
이것은 수치를 낮추는 것이 아니라 **기준을 새로 세우는 것**이다 — 14D 값은 다른 모델·다른
기록·다른 action layout 에서 나온 것이라 나란히 놓는 것 자체가 오해를 만든다.

## A1 이 할 것

### X1 — 고정 구 이상을 즉시 조사한다 (사용자 판정: 즉시)

P8 을 돌리다 나온 것: **고정 구(움직일 수 없는 로봇 구)가 14D 27 개 → 16D 42 개.**
16D 에서 `arm_6`(손목)이 자유 관절이 됐으니 고정 구는 **줄어야** 맞는데 늘었다. 방향이 반대다.

**왜 급한가**: 고정 구 / 움직일 수 있는 구의 분할이 틀리면 **모든 여유거리 계산이 그 위에서
돈다** — 회귀 기준선까지 포함해서. 잠복해 있으면 뒤에 나오는 모든 수치가 그 위에 쌓인다.

답할 것:
1. 분할이 **어디서** 정해지나 (`파일:줄`). 관절 자유도에서 파생되나, 목록으로 박혀 있나.
2. 16D 에서 42 가 나오는 것이 **옳은가 틀린가.** 옳다면 왜 늘었나.
3. 틀렸다면 **회귀 기준선이 그 영향을 받았나.** 받았으면 어느 방향으로.

### X2 — 16D 정렬 감사 (같은 실마리)

위 조사의 확장이다. **AG3S 안에 14D 가정이 남은 곳**을 훑어라 — 관절 수·action layout·
링크 목록·구 목록이 6/14 를 전제하는 자리. `파일:줄` 로 목록만 내라. **고치는 것은
목록을 보고 판정한 뒤**다. X1 이 그 목록의 첫 항목일 가능성이 높다.

### P5 — R3 을 16D 기록의 파지 구간으로 (사용자 판정: 4 프레임으로 진행)

쓸 수 있는 파지 프레임은 **32~35 넷뿐**이다 (호출 36 부터 세 카메라 모두 사과 픽셀 0 —
그리퍼가 완전히 가린다). **표본이 4 라는 것을 산출물에 명시**하고 진행한다.
`--thresholds` 상한도 넓혀라 — 1 차가 고른 3.0 이 후보 목록의 상한값이었다.

**14D 의 1.5 복셀과 비교하지 마라.** 16D 에서 얼마인가만 낸다.

## A3 가 할 것 — R 절을 16D 단독으로 다시 쓴다

**값 표에서 `14D 값` 열과 `달라졌나·왜` 열을 없앤다.** 새 열은 `16D 값 │ 어떻게 쟀나 │ 표본`.

- 이미 닫힌 **N2**(아는 정적 기하를 담을 geometry 채널이 없어 격자 밖·미관측이 무조건 자유로
  답해졌던 것 → `min(복셀, 해석적)` 해석적 채널)의 16D 값은 그대로 두되, *"14D 와 같은 결론"*
  같은 비교 문장을 걷어낸다. **16D 에서 채널을 켜면 낙관 0 이다** 로만 적는다.
- 14D 값을 지우는 것이 아니라 **기준의 자리에서 내리는 것**이다. 판정 근거로 쓰지 않는다는
  사실과 그 이유(다른 모델·기록·action layout)를 한 단락으로 남겨라 — 나중에 이 표를 보는
  쪽이 "왜 14D 가 없나" 를 묻지 않도록.
- `AG3S_REVIEW_LOG.md`(archive)는 **고치지 않는다.** 거기는 14D 국면의 기록이고 그대로 둔다.
- 사용자 판정 6·7 을 추가: (6) 14D 와 비교하지 않는다 (7) 고정 구 이상을 즉시 조사한다.
