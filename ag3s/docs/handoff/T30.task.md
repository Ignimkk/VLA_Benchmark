## 수정 (→ implementer, 파일 소유 셋으로 나눔)

### T30a — F1 + F4 (`trajopt/linearize.py` · `trajopt/grasp_latch.py` · `trajopt/safe_policy.py` 의 판정 분류/latch 호출부)

- **F1**: target-free 층에서 답을 받은 권한 행(`target_free_mask` 행)에는 `manipulated_link_margin` 을 **적용하지 않는다** — 그 층에는 조작 대상이 없으므로 "조작 대상 행" 판정 자체가 뜻이 없다.
  그 행의 여유는 `esdf_margin` (+ 목적지 규칙) 뿐이다. 권한 없는 행 · target-free 가 꺼진 정책(`relax`)은 **지금 그대로** (phase 여유 유지).
  AG3S 쪽 clearance 계산(`to_adapter`/pipeline 의 `clearance` 배열)과 판정 분류(`verdict_reasons`: `answer_excludes_target` → `collision`)가 같은 규칙을 쓰는지 확인하고, 갈라지면 맞춘다.
  **판정은 느슨해지지 않는다**: target-free 층에서의 위반은 여전히 사과 아닌 무언가(테이블·crate·이웃 과일)와의 충돌이다.
- **F4 (T22b)**: `settled` 를 "명령 누적 스텝" 이 아니라 **측정 개도의 정지** (연속 두 요청의 측정 개도 차 < ε, ε 는 기록에서 정해 근거를 적는다)로. 빈손(완전 닫힘까지 감)과 쥔 손(중간에서 멈춤) 구별은 T22 그대로.
  근거 수치: T17 실제 파지 1.013 → 0.904 → 0.712 (2 스텝에 정착) · 빈손 sweep 10/24 attach (chunk 경계에서 손가락 이동 중 0.16–0.76).

### T30b — F3 + F5 (`ag3s/stages/target_grounding.py` · `ag3s/stages/admissibility.py` · `ag3s/experiments/sources/mujoco_source.py` · `ag3s/robot_models/**`)

- **F3**: 파지 전(`frozen=False`) manipulated 의 `keep/hold` 연결은 **(i) centroid 이동 ≤ 물체 자신의 반지름** (마지막 admissible 기하의 bounding radius), **(ii) 크기 일관성** (narrowest/중간 extent 가 마지막 admissible 기하 대비 허용 비율 안 — 비율은 기록에서 정해 근거를)
  둘 다일 때만. 아니면 연결하지 않고 `occluded` (마지막 admissible 기하 유지, 사유 `association_rejected` + 이동량/크기비 기록). 테이블 위 물체는 손이 닿기 전 움직이지 않는다 — 이것이 (i) 의 근거다.
  `switch` 규칙(T26: admissible + score ≥ 0.1 × 3 프레임)은 그대로. 숫자 `tolerance` 를 키우거나 줄이는 것으로 해결하지 않는다.
- **F5**: self-filter 덮개(T29 `SELF_FILTER_COVER_BODIES`)에 `base` 와, 기준선 기록 `run_16d_ep1800` 에서 inflation 0 으로 새는 나머지 body 를 더한다 (GT segmentation 으로 확인 — T29 의 자가 점검 방식). 제약 모델은 불변.
