## 무엇을 했나 (평이한 요약 먼저)

사다리 실험(E1 "TO only" → E2 +목적함수·limit → E3 +거리장)을 **판정·HOLD 없이** 돌릴 수 있게 스위치 넷을 만들었다.

1. **로컬 `--safe-gate off`** — 도착한 청크는 서버 판정과 무관하게 **refined** 를 실행한다. 판정은 계산해서 기록만 한다
   (`gate: {mode: off, would_hold, kinds, would_hold_kinds}`). HOLD 는 청크가 **도착하지 않은** 경우(timeout·stale·error·dimension)뿐이고,
   그때마다 `!!! GATE OFF but chunk seq N did NOT arrive` 로 크게 찍고 `comms_holds` 로 센다. `--safe-shadow` 와 같이 주면 거절.
2. **서버 `--no-perception`** — 새 모듈 `trajopt/to_only_policy.py`. π0.5 → TO 만 돈다. AG3S·depth·ESDF·attention 두 번째 사본·grasp latch 를
   **하나도 만들지 않는다.** 같은 와이어(`actions`=refined · `actions_reference` · `to` · `safe=True` · `verdict_reasons=[no_perception]`)라
   기존 `--safe-remote` 클라이언트가 그대로 받는다. 최적화기에는 "어디서나 +inf 를 답하는 거리장" 하나를 실은 **빈 세계**를 준다 —
   씬이 비면 `sqp` 가 SQP 를 건너뛰고 reference 를 통과시키기 때문이다(그것은 "TO 없음" 이다). `sqp.py` 는 한 줄도 안 바꿨다.
3. **서버 `--no-limits`** — QP 에서 joint position box · 스텝 사이 속도 행 · 가속도 행을 뺀다. **남긴 것: SQP trust region 과 첫 스텝 anchor**
   (`|Q0 − q_now| ≤ v_max·dt`). 추적 항만 두면 refined ≡ reference 다 — 단위 시험에서 **비트 단위로 같다** (T15 fixture: limit 을 켜면 2.547 mm 움직이던 것).
4. **`--links` 기본값 `arms` → `gripper`** — 거리장 충돌 제약은 손바닥 둘 + 손가락 넷에만. `arms`·`all` 이 이제 크게 경고되는 비기본이다.
   자기 필터 모델(전신)은 그대로.

실제 서버(포트 8209)로 E1 smoke 를 3 청크 돌렸다: 서버 기록의 refined − reference **0.0°** (3/3, `returned=initial`), 로컬 24/24 스텝 실행,
comms HOLD 0. 서버는 끝나고 죽였다. **측정은 아니다** — 사과를 잡는지는 verifier(T28)가 잰다.

## 1. `--safe-gate off` (client · `pi05_infer.py`)

| 상황 | 실행 | `last_gate` | `last_safe` / `last_ipc` / `stats` |
|---|---|---|---|
| 도착 · 사유 표로 실행 | refined | `{mode: off, action: execute, would_hold: False, kinds, would_hold_kinds: [], hold_kinds: []}` | True / `ok` / `safe` |
| 도착 · 사유 표로 HOLD (collision · uncertified · no_perception · 서버 `safe=False` …) | **refined** | `would_hold: True, would_hold_kinds: [...]` | False / `unsafe` / `unsafe` + `gate_off_override` (일어날 때만 키) |
| 도착하지 않음 (comms 넷) | **fixed HOLD** (T23 `HoldController`) | `hold_kinds: ["comms"]` | False / `timeout`·`stale`·`error` + `comms_holds += 1` + 크게 찍음 |

- **판정 값은 판정 그대로다** (shadow 와 같은 규율) — 실행 사실은 `last_executed_chunk="refined"` 가 따로 말한다. 한 값이 둘을 겸하면 기록에서
  되살릴 수 없다.
- `would_hold` 는 `reasons` 게이트였다면의 결정이다 (서버 `safe=False` 는 로컬 표가 실행이어도 `server_unsafe` 로 HOLD 쪽).
- 시작 배너(`client.gate_banner`)와 종료 요약: `[safe] GATE OFF: executed the refined chunk on N/M chunks; a reasons gate would have held K (kind n …); comms HOLD C` —
  C 가 0 이 아니면 `!!! (must be 0 for a no-HOLD run)` 가 붙는다.
- `pi05_infer.py` 는 planning frame 의 `gate` 에 `dict(safe_client.last_gate)` 를 이미 싣고 있어서 (T23) `would_hold` · `kinds` 가 그대로 탄다. 제어 루프 본문은 안 바꿨다.

## 3. `--no-limits` — 무엇을 뺐고 무엇을 남겼나

| | `--no-limits` | 어디서 |
|---|---|---|
| joint position box | **뺌** (`lower/upper = ∓inf`) | `limits.build_limits` (`enforce_position=False`) |
| 스텝 사이 속도 행 | **뺌** | `problem.build_problem` (`velocity_rows(limits)` 가 False) |
| 가속도 행 | **뺌** (`max_step_change = inf`, 예전 `enforce_acceleration=False` 그대로) | 〃 |
| **SQP trust region** | **남김** — box 블록은 이제 `iterate ± trust_radius` 뿐 | `problem.py` box 블록 |
| **첫 스텝 anchor** `\|Q0 − q_now\| ≤ v_max·dt` | **남김** | `RelaxedJointLimits(velocity_rows=False)` — `max_step` 을 **유한하게 둔 채** 속도 행만 끈다 |

- anchor 를 값 `inf` 로 지우지 않고 표시로 남긴 이유: `sqp._limit_overshoot` 가 초기 iterate 의 적격성(T24)을 **같은 `max_step`** 으로 잰다. 두 곳이 다른 값을 보면
  QP 와 적격성 검사가 갈라진다. `limit_report` 도 걸지 않은 속도 한계는 위반으로 세지 않는다 (세면 초기 iterate 가 부적격이 되어 reference 가 끌려간다).
- 정의는 `config.NO_LIMITS` 한 곳 (`enforce_position/velocity/acceleration=False, keep_anchor=True`). 새 필드 `enforce_position`(기본 True) · `keep_anchor`(기본 False)는
  **기본값에서 예전과 글자 그대로 같다** — `enforce_velocity=False` 단독의 예전 뜻(anchor 도 없음)도 그대로다 (`test_limits.py` 가 박고 있다).
- `--w-track 0` 거절은 그대로 (T15) — 테스트로 다시 박았다.

### 발견 — anchor 밖 reference 의 후보 선택 (T24 영역, 고치지 않음)

첫 스텝이 anchor 밖이면(초기 iterate 부적격) **반환값이 anchor 를 다 지키지 않는다**: 0.020 rad(1.15°) 초과 중 0.015 rad 만 당긴다. QP 후보는 전부 초기 merit 보다 나빠
거절되고 → trust region 이 0.01 까지 줄고 → box(trust ∩ anchor)가 교차해 중점으로 접힌 후보가 가장 작은 merit 으로 `best_unaccepted` 가 된다.
**limit 을 켠 판에서도 똑같다** (같은 fixture, 0.0150 rad) — 이 STEP 이 만든 것이 아니다. E1 에서 정책 첫 스텝이 v_max·dt 를 넘으면 refined ≠ reference 가 되고,
그 크기는 기록의 `sqp.initial_limit_overshoot.anchor` · `sqp.returned` 로 읽힌다. → 판정 요청 2.
