# P0b 결과 — Attention이 실제로 타깃을 지목하는가

논문 전체가 얹혀 있는 관찰 하나를 검증한다. 실패하면 CBF-QP를 구현할 이유가 없다
([06-repro-plan.md](06-repro-plan.md) §8.1).

**결론: PASS. 핵심 주장과 "layer 12" 선택 모두 재현된다.**

| 항목 | 내용 |
|---|---|
| 모델 | `pi05_libero` (frozen), H200 |
| 데이터 | **4 suite**(spatial/object/goal/10) × 5 태스크 × 2 에피소드 = **40 에피소드** |
| 채점 스텝 | **1,479** (원본 220스텝 롤아웃, `--stride 4`) |
| 타깃 정답 | BDDL 목표 술어 → 세그멘테이션 인스턴스로 해석 |
| 단계 | 그리퍼 첫 폐쇄를 경계로 접근/배치 분리 |
| 마스크 | robosuite GT instance segmentation (지각 오차 없음) |
| 파라미터 | $\beta = -1$ (논문), $K = 5$ ([ASSUMPTION]) |
| 로그 | `data/p0b_sweep.log` |

## 1. 핵심 주장 성립

| 조건 | 적중률 |
|---|---:|
| 논문 셀 (layer 12, head 3) | **0.682** |
| 144개 헤드 평균 | 0.325 |
| shuffled attention 통제 | 0.188 |
| uniform attention 통제 | 0.232 |
| 우연 (계산값) | 0.199 |

우연 수준이 0.143이 아니라 **0.199**인 이유: `libero_10`처럼 목표가 둘인 태스크
("put **both** the soup **and** the sauce in the basket")와 객체 수가 적은 장면
(`moka_pot` 3개 후보)이 섞여 있어, 스텝별 `|타깃 집합| / |후보|`의 가중평균으로 계산했다.

**shuffled 통제(0.188)가 우연과 일치**하는 것이 핵심 근거다 — 실제 attention 값을 유지한 채
패치 위치만 섞으면 신호가 사라진다. 즉 정보는 값 분포가 아니라 **공간적 대응**에 있다.

> uniform 통제(0.232)가 우연보다 약간 높은 것은 지표 결함이 아니라 축퇴 때문이다. 평탄한
> 그리드는 면적 정규화로 모든 객체를 **정확히 동점**으로 만들고, `argmax`는 후보 배열의 0번을
> 고른다. 0번은 에피소드마다 무작위지만 에피소드 안에서는 고정이라, 40개 에피소드로는
> 이항 잡음이 남는다. 의미 있는 통제는 shuffled 쪽이다.

## 2. 논문의 layer 12 선택이 재현된다

레이어별 8개 헤드 평균:

```text
L0  0.181   L6  0.224   L12 0.625  ← 최고
L1  0.098   L7  0.229   L13 0.556
L2  0.160   L8  0.369   L14 0.458
L3  0.154   L9  0.509   L15 0.480
L4  0.106   L10 0.345   L16 0.446
L5  0.226   L11 0.343   L17 0.345
```

논문 §3.4: *"layer-wise averages for the agent camera peak at layer 12, followed by layer 8."*

- **layer 12 정점 — 일치** [PAPER 재현]
- layer 8 차순 — **불일치**. 우리는 L13(0.556) → L9(0.509) 순이고 L8은 0.369로 7위.

셀 단위로도 layer 12가 최상위 행이다:

| 셀 | 적중률 |
|---|---:|
| **(12, 4)** | **0.715** ← 전체 최고 |
| (12, 5) | 0.690 |
| (12, 0) | 0.680 |
| **(12, 3) — 논문** | **0.682** |
| (8, 2) / (9, 5) | 0.700 |

논문이 지목한 (12,3)은 layer 12 안에서 최고는 아니지만(h4가 0.715), **같은 레이어이고 차이가
0.03에 불과**하다. layer 12 행 전체가 0.44–0.72로 고르게 강하다.

> **이전 보고의 정정.** 이 문서의 앞선 판(4 에피소드, `libero_spatial` 단일 장면, 240스텝)은
> "L15가 정점이고 (16,7)이 최고, layer 12는 아니다"라고 적었다. **그 결론은 표본 결함이었다.**
> 당시 4개 태스크는 객체 집합이 동일해 사실상 한 장면이었고, 로봇 인스턴스가 후보에 섞여
> 있었으며, 다중 목표 태스크를 단일 타깃으로 채점했다. 4개 suite로 넓히고 세 버그를 고치자
> 논문과 일치하는 그림이 나왔다. **헤드 인덱스가 이식 불가능하다는 앞선 추정은 철회한다.**

## 3. 접근 단계와 배치 단계가 다르다

논문 셀 (12,3) 기준:

| 단계 | 적중률 | 스텝 수 |
|---|---:|---:|
| 접근 (reach) | **0.853** | 593 |
| 배치 (place) | **0.568** | 886 |
| 우연 | 0.199 | — |

배치 단계도 우연보다 훨씬 높지만 접근보다 뚜렷이 낮다.

> 앞선 판에서 "배치 단계는 우연 수준(0.20–0.30)"이라고 적었던 것도 **표본 결함이었다**(n=5~10).
> 1,479스텝에서는 0.568로, 우연의 2.9배다.

### 함의 — CBF 필터에 실질적 위험

배치 단계 열화의 원인으로 두 가지가 가능하다 [DERIVED, 미검증]:

1. **단계 판정이 거칠다.** 첫 그리퍼 폐쇄를 경계로 삼으므로, 집기에 실패해 다시 열고
   재시도하는 에피소드에서는 "배치"로 분류된 구간에 여전히 접근 중인 스텝이 섞인다.
2. **정책이 배치 중에도 쥔 물체를 계속 본다.** 이쪽이면 KNOWS에 직접적인 문제가 된다 —
   $\tau_t$가 쥔 물체로 남으면 **목적지가 장애물 집합에 들어간다**. 즉 필터가 "놓아야 할 곳"을
   회피하려 든다. Eq. (4)의 $\delta$가 크면 $\varnothing$이 되어 목적지를 포함한 전체가
   장애물이 되므로 마찬가지다.

논문 §5의 한계 목록에 이 항목은 없다. **P3(폐루프)에서 배치 실패율을 반드시 따로 계측해야
한다.** 구분 방법: `success=True` 에피소드만 골라 재채점하면 (1)과 (2)를 분리할 수 있다.

## 4. $\delta$ 설정에 필요한 관측

(12,3)의 top-1 − top-2 density gap:

| 통계 | 값 |
|---|---:|
| median | 1.77e-04 |
| p10 | 7.30e-06 |
| max | 1.63e-03 |

p10이 median의 1/24이다. **약 10%의 스텝에서 1·2위가 사실상 구분되지 않는다.** Eq. (4)에서
이 구간은 $\tau_t = \varnothing$이 되어 전 객체가 장애물이 된다. $\delta$를 median 근처로 잡으면
절반의 스텝에서 타깃 제외가 무력화된다 — $\delta$가 SR/CR을 지배한다는
[03-math.md](03-math.md)의 분석이 수치로 확인된다.
